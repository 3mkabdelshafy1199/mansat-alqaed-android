# مشروع تطبيق منصة القائد (Android APK)

هذا مشروع أندرويد يضم ملفات موقع منصة القائد داخل WebView ويُنتج APK تجريبيًا (Debug APK) عبر GitHub Actions.

## أسهل طريقة لبناء ملف APK
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات هذا المجلد** إليه.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Android APK** ثم اضغط **Run workflow** (أو انتظر اكتمال البناء التلقائي بعد الرفع إلى main).
4. افتح عملية البناء الناجحة، وانزل إلى قسم **Artifacts**.
5. نزّل `mansat-alqaed-debug-apk.zip` وفك ضغطه لتحصل على `app-debug.apk`.
6. انقل APK إلى موبايل أندرويد وافتحه للتثبيت. قد تحتاج السماح بالتثبيت من هذا المصدر في إعدادات أندرويد.

## ملاحظات
- هذا APK تجريبي للتثبيت والاختبار، وليس إصدارًا موقّعًا للنشر على Google Play.
- لا يوجد حسابات مستخدمين أو قاعدة بيانات سحابية؛ تقدم الاختبارات محفوظ محليًا على الجهاز.
- محتوى الدروس الحالي تجريبي ويحتاج استكمال ومراجعة قبل استخدامه كمنصة تعليمية كاملة.
- اسم الحزمة: `com.mansatalqaed.app`، الإصدار 1.0.
